# Phase 8 Readiness Checklist — Interactive Map Viewer & Geospatial Analytics

Before transitioning to Phase 8, the following prerequisites have been verified:

## 1. Prerequisites Checklist
- [x] **Cloud-Optimized GeoTIFF Generation**: Output rasters are single-band float32 with standard 256×256 block tiling and Deflate compression.
- [x] **Geospatial Reference Integrity**: All generated index rasters inherit valid EPSG coordinate reference systems and affine transformations.
- [x] **Statistical Summaries**: Min, max, mean, standard deviation, and valid pixel counts are computed and recorded in `map_products.statistical_summary`.
- [x] **Zonal Vigour Breakdown**: 4-zone classifications (Water/Non-veg, Bare Soil/Sparse, Moderate Vigour, High Vigour) are pre-calculated and stored in `zonal_statistics`.
- [x] **NoData Handling**: Invalid pixels and denominators are standardized to `-9999.0` for clean alpha masking in MapLibre GL JS tile renderers.
- [x] **Storage URIs & Access Endpoints**: Signed and local dev access URLs are generated by `apiClient.getMapProductDetail(productId)`.
- [x] **API Contracts**: Standardized endpoints exist to query products and their zonal statistics.

## 2. Planned Phase 8 Scope
- MapLibre GL JS integration on Page 4 (Secure Farmer Portal & Interactive Map).
- Multi-layer toggle (RGB Orthophoto, NDVI, NDRE, GNDVI, SAVI, DSM/DTM).
- Split-screen before/after swipe comparison.
- Dynamic color-ramp shader styling and continuous value probe.
- Field boundary polygon overlays.
